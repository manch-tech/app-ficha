# App Ficha é um gestor de ficha para uso individual ou em conjunto com outras aplicações ou sites para coletar informações e validar compromisso com o cliente ou qualquer outra contraparte numa relação formal ou informal. Um exemplo aqui é a qualificação de clientes, mas pode ser personalizada conforme a necessidade de cada negócio.

# O app-ficha utiliza banco de dados, confira em: https//manch-tech.github.io/app-ficha
